How the application behaves
Maintenance

Preferences for the application itself. Anything to do with keeping the instance running — backups, storage, the database, the scheduler — lives on the Maintenance page.

Work Orders
On by default — archiving freezes what a record says, it is not a retention lock. Switch it off to make the archive permanent: the Delete button disappears from archived work orders and the server refuses the request even if it is sent directly. Live work orders are unaffected either way.
Attachments
Off means any size is accepted. The only real ceiling then is disk space, and a single very large upload is held in memory or a temporary file while it arrives — worth leaving on unless you have a reason.
