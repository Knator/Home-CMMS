Updates
The only thing in this application that reaches the internet on its own; email goes only to the server set below. Nothing about your instance is sent — it is an unauthenticated request for a public release listing, so GitHub sees an address and nothing more. The answer is cached for six hours, and an instance with no route out simply reports that it could not check.
