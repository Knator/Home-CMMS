{# The "+" beside a record picker. It is a real link to the real create page, so with JavaScript off (or if the modal fails) it still works — it just opens in a new tab. initCreateModal() upgrades it in place: same URL with ?embedded=1, shown in a dialog over the current form, so a half-filled work order is never navigated away from. `target` is the id of the shows with JavaScript off, and what the combobox filters against — so typing "utility" finds everything in the Utility Room, and typing a parent asset's name finds its sub-assemblies. #} {# Where a location sits: its ancestors, root first, not including itself. #} {% macro location_option(loc, selected=False) -%} {%- set context = loc.ancestors | reverse | map(attribute='name') | join(' › ') -%} {%- endmacro %} {# What an asset is part of, then where it is. The parent comes first because it is the thing the location label could never say: a blower motor in the utility room is ambiguous; a blower motor that is part of the furnace is not. #} {% macro asset_option(a, selected=False) -%} {%- set parent_part = ('part of ' ~ a.parent.name ~ ' (' ~ a.parent.asset_number ~ ')') if a.parent else '' -%} {%- set place_part = a.location.path_label if a.location else '' -%} {%- set context = [parent_part, place_part] | select | join(' · ') -%} {%- endmacro %} {# Job plans have no hierarchy, so the context is the description — a column on the row, so it costs no query, unlike a task count would. #} {% macro job_plan_option(jp, selected=False) -%} {%- set context = (jp.description or '') | trim -%} {%- endmacro %}
