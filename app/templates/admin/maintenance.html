Restore

Replaces the database and every uploaded file with the contents of a backup. Everything currently in this instance is discarded. A copy of the current state is archived first as pre-restore-… so a mistake can be undone, the archive is checked before anything is touched, and any pending database migrations are applied afterwards so an older backup still opens. Everyone is signed out when it finishes.

Anything in {{ status.backups_path }}. Copy an archive there to restore a file this instance did not create — there is no upload size limit that way.
Up to {{ (config.MAX_CONTENT_LENGTH // (1024 * 1024)) }} MB; raise MAX_UPLOAD_MB for a larger archive.
Restoring by hand instead

Stop the application, then:

tar -xzf {{ backups[0].name if backups else 'home-cmms-backup-YYYYMMDD-HHMMSS.tar.gz' }} -C /tmp/restore
cp /tmp/restore/home_cmms.db {{ status.database_path }}
rm -f {{ status.database_path }}-wal {{ status.database_path }}-shm
cp -r /tmp/restore/uploads/. {{ status.uploads_path }}/

Then start the application and run flask db upgrade.
